**AI 기반 연구 워크플로우 통합 툴킷**

작성일: 2026-09-06

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | Veloo (벨루) |
| 한 줄 소개 | 논문 읽기·번역·용어 이해·모델 학습·일정 관리를 하나의 워크스페이스로 묶은 AI 기반 연구 툴킷 |

## 2. 문제 정의 (필요성)

연구 진행 시 대학원생/연구자가 오가는 도구.

- PDF 리더 (논문 원문 확인)
- 번역기 (영어 논문 이해)
- 용어 검색/사전 (도메인 용어 정리)
- 노트/암기 앱 (구조 이해, 복습)
- 할 일 관리 및 캘린더 (읽은 내용을 실행으로 전환)

문제는 **각 도구가 서로의 맥락을 전혀 공유하지 못함**. 논문을 읽다가 번역기로 넘어가면 방금까지 읽던 문맥을 다시 설명해야 하고, 용어를 찾아봐도 검색 결과가 할 일 관리로 이어지지 않음. 도구를 전환할 때마다 지금 하던 작업을 새로 복원해야 하는 비용이 반복적으로 발생.

또한 기존 개별 도구들의 한계.

- **번역기**: 일반 번역기는 ML(Machine Learning)/DL(Deep Learning)/CV(Computer Vision)/NLP(Natural Language Processing) 분야의 수식·고유명사·전문용어를 문맥 없이 직역해 오히려 이해를 방해.
- **논문 관리 툴**: 논문을 열람만 시켜줄 뿐, 저널/학회의 질적 수준(venue quality)을 사전에 판단할 근거를 주지 않아 좋은 논문과 약한 venue의 논문을 구분하는 데 시간 소요.
- **용어 사전**: 하나의 용어가 논문마다 다른 의미로 쓰이는 경우(같은 단어가 분야별로 다르게 정의되는 경우)를 반영하지 못하고 단일 정의만 제공.
- **다이어그램 학습**: 아키텍처 다이어그램을 눈으로 훑고 넘어가는 데 그치며, 실제로 이해했는지 스스로 검증할 방법 없음.

**Veloo는 5가지 흐름(읽기 > 번역 > 용어 이해 > 구조 학습 > 실행 계획)을 하나의 로그인, 하나의 히스토리 아래에 묶어, 도구 전환 비용 자체를 없애는 것을 목표로 함.**

---

## 3. 솔루션 개요

Veloo는 승인된 계정마다 `/:username` 개인 워크스페이스를 제공하며, 아래 5개 모듈이 탭 형태로 한 화면 안에 배치되어 클릭 한 번으로 전환된다. 모든 모듈은 같은 로그인·같은 히스토리를 공유하므로, 한 모듈에서 만든 맥락(읽은 논문, 찾아본 용어 등)이 다른 모듈로 이어질 수 있는 구조다.

핵심 가치 제안: **"6개의 탭을 오가지 말고, 하나의 워크스페이스에서."**

---

## 4. 기능 명세 (모듈별 요약)

각 모듈은 독립적으로도 쓸 수 있지만, 같은 계정·같은 히스토리를 공유하는 하나의 워크스페이스 안에 있다는 전제로 설계되어 있다. 모듈별 "왜 필요한가 – 무엇을 하는가 – 어떻게 쓰는가 – 무엇이 좋아지는가" 상세 설명은 [docs/features_ko.md](features_ko.md)로 옮겼다.

| 모듈 | 한 줄 요약 |
|---|---|
| Paper (Paper Analyzer) | 논문 업로드/검색 → AI 요약 + SJR 저널 품질 점수로 읽기 전 사전 판단 |
| Trans (Translator) | ML/DL/CV/NLP 특화 영→한 스트리밍 번역 |
| Concepts (Contextor) | 용어를 논문/분야별 맥락으로 분리해서 구조화된 의미 제공 |
| Models (Model Review) | 아키텍처 그림을 직접 설명 → AI 레퍼런스와 비교 채점 (액티브 리콜) |
| Plan (Todo + Calendar) | AI 단계 분해 + 드래그 앤 드롭 주간 타임블로킹으로 실행까지 연결 |

---

## 5. UI 구조

- 하단 캡슐형(iOS 리퀴드 글래스 스타일) 탭바로 5개 모듈(Plan / Paper / Trans / Models / Concepts) 간 전환
- 활성 탭은 캡슐형 인디케이터로 강조 표시
- 모든 모듈이 동일한 워크스페이스 내에서 한 클릭 거리로 연결

## 6. 기술 스택 및 아키텍처

| 레이어 | 기술 |
|---|---|
| Backend | FastAPI, Python 3.11, Uvicorn |
| Frontend | React 18, TypeScript, Vite |
| AI | Anthropic Claude (기본), Gemini (대체 가능한 스왑형 프로바이더) |
| DB / 인증 | Supabase (인증 + 모듈별 히스토리 저장) |
| 배포 | Docker, Cloudflare Tunnel, GitHub Actions |
| 개발 도구 | Claude Code (에이전틱 코딩) |

로컬 실행 기준:
- 백엔드: `python -m backend.main` > `http://localhost:9000`
- 프론트엔드: `npm run dev` > `http://localhost:5173`
- Docker 이미지 빌드 및 실행 지원
