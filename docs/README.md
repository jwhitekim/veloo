# 문서 색인

veloo 프로젝트 문서 목록. "지금 시스템이 어떻게 동작하는가"는 [`openspec/specs/`](../openspec/specs/)가 단일 진실이고, 여기 `docs/`는 그 외 참고 자료(제품 내러티브, 디자인 토큰, 설계 히스토리, 리포트)를 모아둔다.

## 살아있는 스펙 (openspec/specs/)

- [auth](../openspec/specs/auth/spec.md) - 로그인/회원가입/세션 미들웨어
- [paper-analyzer](../openspec/specs/paper-analyzer/spec.md) - 논문 검색·분석
- [translator](../openspec/specs/translator/spec.md) - 스트리밍 번역
- [model-review](../openspec/specs/model-review/spec.md) - 아키텍처 설명·채점
- [todo](../openspec/specs/todo/spec.md) - 할 일·단계·리마인드
- [contextor](../openspec/specs/contextor/spec.md) - 용어 맥락별 조회
- [product](../openspec/specs/product/spec.md) - 제품 원칙, 페이지 계약, 완료 기준, 변경 절차
- [mobile-navigation](../openspec/specs/mobile-navigation/spec.md) - iOS 캡슐 독 / Android 하단 바 동작

진행 중인 변경 제안은 [`openspec/changes/`](../openspec/changes/) 참고 (예: [verify-android-navigation](../openspec/changes/verify-android-navigation/proposal.md)).

## 참고 자료 (docs/)

- [프로젝트 명세서](veloo-spec.md) - 문제 정의, 솔루션 개요, 기술 스택
- [UI 디자인 시스템](ui-design-system.md) - 색상 토큰, 타이포그래피, 레이아웃 규칙
- [iOS 캡슐 내비게이션 설계 히스토리](ios-capsule-navigation.md) - 지금 값이 왜 이렇게 됐는지 시행착오 기록(현재 동작 자체는 `mobile-navigation` 스펙 참고)
- [캡슐 내비게이션 디자인 조사](capsule-navigation-research.md) - 탭 인디케이터 디자인 참고 자료
